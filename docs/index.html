A team, not a chat window.

Only builders can change code. Everyone else checks or scouts, with no edit tools at all, so a reviewer can never quietly fix what it was asked to judge.

CEO

the /<project>-ceo skill

The chief of staff. It assesses, decides, writes the briefs, verifies through the review board and the release gate, and ships behind a PR. It does not do department work.

Every run follows the same cycle.

Green gates are necessary, not sufficient. The review board exists for the defects no test can see.

  1. PreflightKill switch, clean tree, autonomy level, open PRs, org health.
  2. AssessReport-only specialists, in parallel.
  3. DecideRe-verify each finding at file:line. Rank. Cap the run.
  4. BuildThe owning editor, a playbook, a proving test, a branch.
  5. Review and gateAdversarial lenses and the release gate together, on a frozen tree.
  6. Records, then PRMemory, scorecard, a retro line. Then the PR.

Autonomy is earned, one level at a time.

An org starts where its tests can prove a change correct. Promotion needs scorecard evidence and your approval. A revert demotes it on its own.

L0

Observe

Audits, bug discovery, proposals. Records only.

L1

Verify

Fix PRs, one at a time. You merge.

L2

Constrain

Adds scheduled headless runs.

L3

Parallelize

Parallel worktrees. Agents merge green PRs; you sample after.

L4

Cloud

Always-on routines, same gates.

Most orgs start at L1. Only you raise the level. Every level keeps the same gates and the same review board: a level unlocks capabilities, never shortcuts.

Measured, not claimed.

Agents are tested like code. /org-eval checks out the commit before a real fix and asks the agent to review it, then a different model scores the answer.

The shortcuts are blocked, not discouraged.

A guard hook enforces the rules that matter. It binds the org, never you: your own sessions work as they always have.

Blocked for everyone

Never right, whoever is driving.

  • gh pr merge --admin
  • Force pushes without a lease
  • --no-verify on commits and pushes
  • Edits to the files that define the gates

Blocked during an org run

The autonomy level, enforced.

  • Merging below L3
  • Pushing to the base branch
  • git stash, which is shared by every worktree

It gets better every run.

Memory has owners and budgets, so lessons stay sharp instead of piling up.

Lessons
Agents report durable lessons; the CEO curates them. Only a short active list enters each brief.
Scorecard
Every PR's fate: landed clean, edited, reverted. It is the evidence for each promotion.
Evals
A bug a human had to find becomes a test case, so the same miss cannot happen silently again.
Feedback, opt-in
Problems with the templates themselves can go back to agent-org as an issue or PR, details stripped, sent only on your yes.
